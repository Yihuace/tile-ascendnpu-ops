## 2. Stage-4 优化成果（9.0.0）

| 算子 | 优化方法 | 代表性收益 |
|---|---|---|
| AddFwdOp | 满块静态 extent + 流水 + fp16 原生 vadd | 整体 −1.16%，10/11 ≥70% |
| SubFwdOp | 同构移植 + fp16 原生 vsub | 整体 −0.27%，15/15 ≥70% |
| ClampScalarFwdOp | 去冗余 NaN 恢复（5→3 op） | 上一代工具链 下 −38%；9.0 端到端 58.2–70.2% |
| ClampMinFwdOp | 复用 ClampScalar kernel | 9.0 端到端 61.8–68.8% |
| HardsigmoidFwdOp | 去冗余 NaN 恢复 + 修 fp32 UB | fc-wide −40%（上一代工具链 优化过程）；9.0 tie |
| HardswishFwdOp | 诊断 compute-bound | 无（仅 fp32 健壮性修复） |
| GeluAndMulFwdOp | dtype 分化 erf 阶数 + hoist 常数 | prefill **−43.6%** |
| GeluTanhAndMulFwdOp | fold + hoist `vbrc` | prefill −8.2% |
| IsinfFwdOp | bf16 `vand(x,0x7FFF)` 6→4 pass | bf16 **−19.4~−19.9%** |
| IsfiniteFwdOp | 同 `vand` 路径 | bf16 **−21.2%** |
| FusedAddLayerNormFwdOp | loads-first 双输入前置装载 | 8b prefill **−23.2%** |
| BatchNormBwdOp | subid 分片（MixCV → Vector 归约） | **−33~−46%** |
| Conv1d / Conv1dBias | unit_stride：co 块切分 + x_pad 跳过；通用：taps-in-K + 直读原生 weight | whisper **15×**、encodec-deep 3.6×；通用 wav2vec2 **17.7×**、encodec-init **4.2×** |
| Conv3dBias | tap 打包 + padded-N 分块 + NDHWC 暂存 | unet **21.3×**、r3d-stem **2.36×** |
| GLADecodeOp | K-tile 16→32 + 超发 persistent 分核 | **−24.2~35.4%** |

> **优化收益与 SOL 达标要分开看**：compute-bound 算子删指令时 `total_fops` 同步下降，ratio 几乎不动（GeluAndMul −43.6% 时延，ratio 43.2%→46.0%）；BatchNormBwd 的 ratio 因 subid 去双计而减半。这类算子以 Task Duration 判定。

## 3. 天花板、豁免与阻塞

| 类别 | 算子 | 证据 |
|---|---|---|
| MTE2 混合读写带宽地板 | Isnan / Isinf / Isfinite（fp16/fp32） | `aiv_mte2_ratio 0.81–0.90 ≫ aiv_vec_ratio 0.25–0.39`；4→3 pass 仅 −3.4%；40 核最优 |
| 计算受限 + 判据失配 | Hardsigmoid / GeluTanh / GeluAndMul / Hardswish | `aiv_vec_ratio 0.85–0.95`、`computility=Vec_FP32(~99%)` |
| latency-bound | GLA / FALN | `advice=latency bound:pipeline caused`；并行度受限 / 15+ pass + 2 reduce |
| fp32 中转结构天花板 | BatchNormBwd / FALN | fp32 中转 + Vec_MISC + 内存 |
| 编译器缺陷（非优化可解） | GDN blocksolve、Conv1d 的 flaky bench | CG-2026-0003（`ConvertHFusionToHIVM` 对 buffer 形态 `mmadL1` 取 `getResult(0)` 越界）；<br>CG-2026-0028（Vector prelude 带列偏移 GM 子区域写 → `Unknown core type: llvm.func @malloc`，阻塞 bias-in-K） |
| 9.0 clamp 链回退 | ClampScalar / ClampMin | 9.0 端到端 58.2–70.2% / 61.8–68.8%，相对 上一代工具链 下降；待同链路 A/B 定性 |
| 微型 shape 豁免 | Hardsigmoid ×4、Gelu ×1、FALN ×2、GLA smoke | Task Duration ≤5µs 或启动开销 ≥50% |
