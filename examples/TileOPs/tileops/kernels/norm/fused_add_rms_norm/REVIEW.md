**核心判定的独立复核(本审阅重点):`1/sqrt` 改写的必要性**

设计把 §0.6 重设计项 3 定为:因 **`T.vrsqrt` 实测 ~2.7e-3 误差超过 fp16 容差 1e-3**,改用 `vsqrt + vdiv`。本审阅核对:

- 依据来源是**既有实现的 docstring 明文记录**(非推测),且明确给出"该误差已超 fp16 容差"的判定;
- 该组合**与仓内 `ada_layer_norm` 的既有约定一致**(docstring 原文:"the same composition the in-repo `ada_layer_norm` kernel adopted for the same reason")⇒ **不是本设计首创的偏方**;
- 等价性论证成立:`1/sqrt(v) == sqrt(v)/v` 对 $v>0$ 恒等,而 $v = \text{mean}(s^2)+\epsilon > 0$ 由 `eps` 保证(即使 $s\equiv0$ 也有 $v=\epsilon>0$);
- §9.2 已把 **`rstd` 精度**与 **`eps` 生效(全零行)** 列入 L1 阻塞用例。

⇒ **判定正确**,且**属第三种 API 情形("指令存在但精度不足")** —— 与 `cos` 的"定义域不足"并列。

**其余三处硬约束的独立核对**

| 约束 | 设计声明 | 本审阅核对 |
|---|---|---|
